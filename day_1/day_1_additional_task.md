# Day 1 — Дополнительная задача

## Контекст

Сделай в `day_1` систему управления пользователями для интернет-магазина.

---

## 1. `UserProfile` — interface

Создай интерфейс `UserProfile`:

- `phone` — необязательное поле `string`
- `address` — необязательное поле `string`
- `age` — необязательное поле `number`

`id`, `name`, `email`, `role`, `isActive` сюда не добавляй — они уже есть в `User`.

---

## 2. Измени `User`

`User` должен реализовывать `UserProfile`.

Добавь в `User` возможность хранить данные профиля.

Условия:

- `phone`, `address`, `age` могут отсутствовать.
- При создании пользователя они не обязательны.
- Добавь метод `updateProfile(profile)`.
- Метод должен обновлять **только переданные поля**.
- Если передан `{ phone: "123" }`, `address` и `age` менять нельзя.
- Если передан `{ age: 30, address: "Belgrade" }`, должны измениться только эти два поля.

---

## 3. Метод `getInfo()`

Измени `getInfo()` так, чтобы он использовал данные профиля.

Пример пользователя со всеми данными:

```text
Ivan (admin) - active
Phone: 123456
Address: Belgrade
Age: 30
```

Но необязательные поля **не выводить**, если их нет.

Например пользователь без профиля:

```text
Ivan (admin) - active
```

Не надо вручную прописывать отдельные варианты строк для каждого случая — используй условия и свойства объекта.

---

## 4. `UserManager`

Добавь методы:

```ts
getUserNames(): string[]
```

Возвращает имена **всех** пользователей через `map`.

```ts
getUsersWithPhone(): User[]
```

Возвращает только пользователей, у которых указан `phone`, через `filter`.

```ts
findUserByEmail(email: string): User
```

Ищет пользователя через `find`.

Если пользователь не найден — выбрасывает ошибку.

---

## 5. Управление статусом

Добавь:

```ts
activateUser(id: string)
```

Условия:

- пользователь должен существовать;
- если уже активен — ничего не ломаем;
- после вызова пользователь активен.

И:

```ts
deactivateUser(id: string)
```

Условия:

- пользователь должен существовать;
- после вызова пользователь неактивен.

Используй уже созданные методы `User.activate()` / `User.deactivate()`.

---

## 6. Роли

Используй существующий:

```ts
type UserRole = "admin" | "manager" | "user"
```

Добавь:

```ts
getUsersByRoles(roles: UserRole[]): User[]
```

Например:

```ts
getUsersByRoles(["admin", "manager"])
```

должен вернуть **и админов, и менеджеров**.

Используй `filter`.

---

# Что будет проверяться

| Тема | Где должна проявиться |
|---|---|
| `interface` | `UserProfile` |
| optional properties | `phone`, `address`, `age` |
| union type | `UserRole` |
| class | `User`, `UserManager` |
| constructor | `User` |
| public/private | поля / `users` |
| methods | методы из задания |
| `this` | методы классов |
| массив объектов | `User[]` |
| `find` | поиск по email |
| `filter` | пользователи с телефоном / роли |
| `map` | имена пользователей |

## Ограничение

Не добавляй функциональность, которой нет в задании. Проверка будет выполняться строго по условиям выше.
